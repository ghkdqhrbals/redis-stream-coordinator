# Redis Stream Coordinator 0.3.4 릴리즈

릴리즈 날짜: 2026-06-16

Native image coordinator metadata JSON serialization 문제를 보강한 patch 릴리즈다.

## 릴리즈 모듈

| 모듈 | Artifact | 상태 |
| --- | --- | --- |
| Coordinator server | Docker image | deploy workflow로 릴리즈 |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.4` | Maven Central 릴리즈 |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.4` | Maven Central 릴리즈 |
| Python client | N/A | 릴리즈 안 함 |

## 호환성

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 권장.

## 변경사항

* Store가 `ObjectMapper`를 직접 호출하지 않고 `CoordinatorJsonCodec` 직렬화 경계를 사용하도록 정리했다.
* Group metadata snapshot 저장 전에 Kotlin 빈 컬렉션 singleton을 정규화한다. `emptySet()`, `emptyList()`, `emptyMap()` 경로를 모두 검사한다.
* Native image에서 `kotlin.collections.EmptyList` reflection 때문에 heartbeat metadata 저장이 실패하던 문제를 방지한다.
* Redis/JDBC metadata serialization 회귀 테스트를 빈 컬렉션 전체로 확장했다.

## Maven Central 사용

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.4")
```

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-core:0.3.4")
```
