# Redis Stream Coordinator 0.3.3 릴리즈

릴리즈 날짜: 2026-06-16

Native image coordinator metadata serialization 문제를 수정한 patch 릴리즈다.

## 릴리즈 모듈

| 모듈 | Artifact | 상태 |
| --- | --- | --- |
| Coordinator server | Docker image | deploy workflow로 릴리즈 |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.3` | Maven Central 릴리즈 |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.3` | Maven Central 릴리즈 |
| Python client | N/A | 릴리즈 안 함 |

## 호환성

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 권장.

## 변경사항

* Redis/JDBC에 coordinator group metadata를 저장하기 전에 Kotlin `emptySet()` singleton을 직접 직렬화하지 않도록 persistence snapshot을 정규화한다.
* Native image에서 `kotlin.collections.EmptySet` reflection 때문에 heartbeat metadata 저장이 실패하던 문제를 방지한다.
* Kotlin empty set singleton이 metadata serialization까지 도달하면 실패하는 Redis/JDBC 회귀 테스트를 추가했다.
* 이미 저장된 손상 metadata는 기존 `COORDINATOR_METADATA_CORRUPT` 응답으로 명확히 드러낸다.
