# Redis Stream Coordinator 0.3.5 릴리즈

릴리즈 날짜: 2026-07-04

Redis Cluster 외 Redis topology 지원을 확장한 patch 릴리즈다.

## 릴리즈 모듈

| 모듈 | Artifact | 상태 |
| --- | --- | --- |
| Coordinator server | Docker image | deploy workflow로 릴리즈 |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.5` | Maven Central 릴리즈 |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.5` | Maven Central 릴리즈 |
| Python client | N/A | 릴리즈 안 함 |

## 호환성

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 권장.

Redis data plane은 standalone Redis, Redis Sentinel, Redis Cluster를 지원한다.

## 변경사항

* Coordinator server와 Spring Boot starter에 Redis connection-details normalization을 추가했다.
* 빈 Cluster, Sentinel, master-replica topology 값은 없는 값으로 처리해 빈 환경변수나 configtree 파일이 있어도 standalone Redis가 정상 동작한다.
* 유효한 Cluster/Sentinel property가 있으면 해당 topology 설정을 그대로 사용한다.
* Standalone Redis에서 shard placement diagnostics를 수집할 때 raw `CLUSTER SLOTS` command를 보내지 않는다.
* Standalone Redis URL 설정에서 `rediss://` SSL 동작을 유지한다.
* Docker smoke stack과 문서를 `REDIS_URL`, standalone, Sentinel, Cluster 설정 기준으로 갱신했다.
