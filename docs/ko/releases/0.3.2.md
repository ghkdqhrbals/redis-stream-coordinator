# Redis Stream Coordinator 0.3.2 릴리즈

릴리즈 날짜: 2026-06-16

Redis-backed coordinator metadata 안전성을 위한 patch 릴리즈다.

## 릴리즈 모듈

| 모듈 | Artifact | 상태 |
| --- | --- | --- |
| Coordinator server | Docker image | deploy workflow로 릴리즈 |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.2` | Maven Central 릴리즈 |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.2` | Maven Central 릴리즈 |
| Python client | N/A | 릴리즈 안 함 |

## 호환성

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 권장.

## 변경사항

* Coordinator server 기본 state store를 memory가 아니라 Redis로 둔다.
* Redis Stream provisioning이 켜진 상태에서 `coordinator.store.type=memory`를 사용하면 startup을 거부한다.
* Coordinator-wide Redis group/stream index를 `coordinator:metadata` 단일 key에 저장한다.
* Group별 metadata key는 기존 구조를 유지한다.

## Maven Central 사용

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.2")
```

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-core:0.3.2")
```
