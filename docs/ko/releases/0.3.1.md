# Redis Stream Coordinator 0.3.1 릴리즈

릴리즈 날짜: 2026-06-15

Stream 생성 의미, consumer bootstrap, console 정리를 위한 patch 릴리즈다.

## 릴리즈 모듈

| 모듈 | Artifact | 상태 |
| --- | --- | --- |
| Coordinator server | Docker image | deploy workflow로 릴리즈 |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.1` | Maven Central 릴리즈 |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.1` | Maven Central 릴리즈 |
| Python client | N/A | 릴리즈 안 함 |

## 호환성

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 권장.

## 변경사항

* Stream 생성 시 consumer group을 암묵적으로 만들지 않는다.
* 기존 stream에 대한 첫 consumer heartbeat가 group을 자동 등록할 수 있다.
* 0-shard group은 빈 assignment로 bootstrap된다.
* `/console`이 최신 admin console로 열린다.
* Message와 monitoring 페이지가 Scalar 스타일 요청/결과 레이아웃을 사용한다.

## Maven Central 사용

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.1")
```

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-core:0.3.1")
```
