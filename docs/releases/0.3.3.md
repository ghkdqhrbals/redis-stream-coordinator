# Redis Stream Coordinator 0.3.3 Release

Release date: 2026-06-16

Patch release for native-image coordinator metadata serialization.

## Released Modules

| Module | Artifact | Status |
| --- | --- | --- |
| Coordinator server | Docker image | Released through deploy workflow |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.3` | Released to Maven Central |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.3` | Released to Maven Central |
| Python client | N/A | Not released |

## Compatibility

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 recommended.

## Changes

* Normalize coordinator group metadata before Redis and JDBC persistence so Kotlin `emptySet()` singletons are not serialized directly in native images.
* Prevent heartbeat persistence failures caused by native-image Kotlin reflection on `kotlin.collections.EmptySet`.
* Add Redis and JDBC regression tests that fail if Kotlin empty set singletons reach metadata serialization.
* Keep the existing `COORDINATOR_METADATA_CORRUPT` response for already-corrupted persisted metadata.

## Maven Central Usage
