# Redis Stream Coordinator 0.3.2 Release

Release date: 2026-06-16

Patch release for Redis-backed coordinator metadata safety.

## Released Modules

| Module | Artifact | Status |
| --- | --- | --- |
| Coordinator server | Docker image | Released through deploy workflow |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.2` | Released to Maven Central |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.2` | Released to Maven Central |
| Python client | N/A | Not released |

## Compatibility

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 recommended.

## Changes

* Coordinator server defaults to Redis-backed state instead of memory-backed state.
* `coordinator.store.type=memory` is rejected when Redis Stream provisioning is enabled.
* Coordinator-wide Redis group and stream indexes are stored under one key, `coordinator:metadata`.
* Group-specific metadata keys remain unchanged.

## Maven Central Usage

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.2")
```

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-core:0.3.2")
```
