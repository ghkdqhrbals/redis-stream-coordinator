# Redis Stream Coordinator 0.3.4 Release

Release date: 2026-06-16

Patch release for native-image coordinator metadata JSON serialization.

## Released Modules

| Module | Artifact | Status |
| --- | --- | --- |
| Coordinator server | Docker image | Released through deploy workflow |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.4` | Released to Maven Central |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.4` | Released to Maven Central |
| Python client | N/A | Not released |

## Compatibility

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 recommended.

## Changes

* Introduce `CoordinatorJsonCodec` so coordinator metadata persistence uses one JSON serialization boundary instead of direct `ObjectMapper` calls from stores.
* Normalize Kotlin empty collection singletons before metadata JSON writes, covering `emptySet()`, `emptyList()`, and `emptyMap()` reachable from group metadata snapshots.
* Prevent native-image heartbeat persistence failures caused by Jackson/Kotlin reflection on `kotlin.collections.EmptyList`.
* Keep Redis and JDBC regression coverage for native metadata serialization.
