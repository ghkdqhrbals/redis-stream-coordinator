# Redis Stream Coordinator 0.3.5 Release

Release date: 2026-07-04

Patch release for Redis topology support beyond Redis Cluster.

## Released Modules

| Module | Artifact | Status |
| --- | --- | --- |
| Coordinator server | Docker image | Released through deploy workflow |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.5` | Released to Maven Central |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.5` | Released to Maven Central |
| Python client | N/A | Not released |

## Compatibility

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 recommended.

The Redis data plane can now run on standalone Redis, Redis Sentinel, or Redis Cluster.

## Changes

* Add Redis connection-details normalization to the coordinator server and Spring Boot starter.
* Treat blank Cluster, Sentinel, and master-replica topology values as absent so standalone Redis remains usable when empty environment variables or configtree files are present.
* Keep Cluster and Sentinel configuration paths active when valid topology properties are configured.
* Avoid issuing raw `CLUSTER SLOTS` commands against standalone Redis when collecting shard placement diagnostics.
* Preserve `rediss://` URL SSL behavior for standalone Redis URL configuration.
* Update Docker smoke stacks and documentation for `REDIS_URL`, standalone, Sentinel, and Cluster settings.
