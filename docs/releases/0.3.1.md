# Redis Stream Coordinator 0.3.1 Release

Release date: 2026-06-15

Patch release for stream creation semantics, consumer bootstrap, and console polish.

## Released Modules

| Module | Artifact | Status |
| --- | --- | --- |
| Coordinator server | Docker image | Released through deploy workflow |
| Spring Boot starter | `io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.1` | Released to Maven Central |
| Shared protocol core | `io.github.ghkdqhrbals:redisstream-core:0.3.1` | Released to Maven Central |
| Python client | N/A | Not released |

## Compatibility

Java 24, Kotlin 2.2.21, Spring Boot 4.0.6, Gradle 8.14.5, Redis 8.8 recommended.

## Changes

* Stream creation no longer creates an implicit consumer group.
* First consumer heartbeat can auto-register a group for an existing stream.
* Zero-shard groups bootstrap with an empty assignment.
* `/console` now opens the latest admin console.
* Message and monitoring pages use a Scalar-style request/result layout.

## Maven Central Usage

```kotlin
implementation("io.github.ghkdqhrbals:redisstream-spring-boot-starter:0.3.1")
```

